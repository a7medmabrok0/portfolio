# Mabroukui

موقع أحمد مبروك على `https://mabroukui.com/`. الموقع ثابت ويعمل مباشرة بملفات HTML وCSS وJavaScript، ولا يحتاج إلى بناء أو حزم برمجية.

## الرفع على الاستضافة

1. ارفع **محتويات** حزمة `Mabroukui.zip` إلى المجلد الذي يقدّم جذر الدومين في الاستضافة (غالبًا `public_html`)، وليس ملف ZIP أو مجلدًا داخليًا باسم `Mabroukui` إذا كنت تريد الموقع على الصفحة الرئيسية.
2. تأكد أن `index.html` موجود مباشرة في جذر الموقع وبجواره `styles.css` و`app.js` و`smooth-follower.js` ومجلد `assets/`.
3. أضف `mabroukui.com` و`www.mabroukui.com` في لوحة الاستضافة، ثم وجّه سجلات DNS وفق القيم التي تعطيها شركة الاستضافة. فعّل شهادة HTTPS، واجعل أحد العنوانين يحوّل إلى الآخر. العنوان الأساسي المستخدم في بيانات الصفحة هو `https://mabroukui.com/`.

لا يمكن تحديد سجلات DNS الصحيحة قبل معرفة شركة الاستضافة وعنوان الخادم أو اسم المضيف الذي خصصته للموقع.

## التشغيل محليًا

من داخل مجلد `Mabroukui`:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ملاحظات المحتوى

- رابط السيرة الذاتية الحالي يشير إلى Google Drive.
- روابط التواصل والبريد الإلكتروني موجودة في `index.html`.
- النسخة الإنجليزية تشمل أقسام الأعمال والخبرات وعني، وتستخدم خط Google Sans واتجاه LTR. النسخة العربية تبقى RTL.
