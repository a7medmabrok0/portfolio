# Mabroukui — النسخة الثانية (v2)

نسخة سينمائية داكنة من البورتفوليو: هيرو بكلمة PORTFOLIO عملاقة خلف البورتريه، شريط أعمال أفقي، قسم «الشغل والأثر»، مقارنة Wireframe ↔ Final UI بالسحب، خط زمني للخبرات، وصفحة تواصل بطائرات ورقية تتفاعل مع الماوس.

- ملف واحد: `index.html` (CSS وJS داخله) + مجلد `assets/` خاص بالنسخة.
- عربي (RTL) افتراضيًا مع زر English، واللغة تُحفظ في المتصفح.
- الخطوط: Ping محليًا للعربي، وAnton / Alexandria / Aref Ruqaa / Caveat Brush / DM Sans من Google Fonts.
- لتجربته محليًا: من داخل مجلد `v2` شغّل `python3 -m http.server 8000` وافتح `http://localhost:8000`.
- للنشر كصفحة رئيسية: انقل محتويات `v2/` إلى جذر الموقع بدل النسخة الحالية، أو ارفعها كما هي لتكون على `mabroukui.com/v2/`.
